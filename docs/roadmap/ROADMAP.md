# ManakAI Product Roadmap

## 1. Roadmap Vision

ManakAI is being developed as a technology prototype for AI-assisted discovery, understanding, and action around BIS-related information.

The roadmap focuses on improving coverage, retrieval quality, verification, integrations, multilingual usability, and production readiness.

## 2. Phase 1 - Current Prototype

### Status: Completed

The current prototype establishes the core application architecture.

Key capabilities:

- React + Vite frontend.
- FastAPI backend.
- Deterministic intent processing.
- Structured knowledge base.
- Hybrid retrieval.
- Safety and confidence gates.
- Decision-engine based responses.
- Optional LLM normalization.
- Evidence-oriented user interface.
- Industry and consumer workflows.

## 3. Phase 2 - Knowledge Expansion

### Status: Planned

Expand the verified knowledge layer to cover a broader range of BIS-related standards, services, products, and workflows.

Planned work:

- Increase verified knowledge coverage.
- Improve source metadata.
- Add structured standard and product relationships.
- Improve knowledge validation workflows.
- Introduce better version and status tracking.

## 4. Phase 3 - Advanced Retrieval

### Status: Planned

Improve retrieval quality for natural-language and multilingual queries.

Planned work:

- Improve semantic embeddings.
- Expand hybrid retrieval strategies.
- Improve entity matching.
- Add query rewriting and normalization.
- Improve multilingual retrieval evaluation.
- Introduce retrieval quality benchmarks.

## 5. Phase 4 - Document Intelligence

### Status: Planned

Introduce controlled document ingestion capabilities for structured knowledge extraction.

Planned work:

- PDF ingestion.
- OCR support.
- Document classification.
- Structured information extraction.
- Source validation.
- Human review workflows.
- Knowledge-base update pipelines.

## 6. Phase 5 - Official Source Integration

### Status: Planned

Where technically and legally appropriate, integrate with official BIS information sources and services.

Potential areas:

- Standard information verification.
- Licence verification.
- HUID-related information.
- Laboratory information.
- Service status.
- Official source links.

All integrations would retain source attribution and verification boundaries.

## 7. Phase 6 - Multilingual Expansion

### Status: Planned

Expand natural-language accessibility for users across Indian languages.

Planned work:

- Improved multilingual query understanding.
- Language-aware retrieval.
- Multilingual response generation.
- Regional-language evaluation datasets.
- Voice interaction improvements.

## 8. Phase 7 - Production Readiness

### Status: Planned

Prepare the platform for reliable deployment beyond the hackathon prototype.

Planned work:

- Authentication and authorization.
- Production database architecture.
- Observability and monitoring.
- API security hardening.
- Rate limiting improvements.
- Automated testing and CI/CD.
- Performance optimization.
- Reliability and disaster recovery planning.

## 9. Long-Term Direction

The long-term objective is to evolve ManakAI from a prototype decision-support assistant into a scalable standards-information platform that helps users discover relevant information, understand requirements, verify evidence, and identify practical next steps.

The system should continue to maintain a clear separation between AI-assisted language processing and authoritative compliance information.

> **Roadmap disclaimer:** Future capabilities are planned directions and are not commitments to specific implementation dates or official BIS integrations.
